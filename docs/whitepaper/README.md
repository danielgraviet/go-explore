# MLSys LaTeX project (Overleaf-ready)

This directory contains the publication LaTeX version of the whitepaper, alongside the preserved Markdown source.

| File | Role |
| --- | --- |
| `returning-to-development-states.md` | Preserved Markdown source (do not treat as the Overleaf entry point) |
| `main.tex` | **LaTeX entry point** for the blind MLSys submission (`main.pdf`) |
| `gtm-main.tex` | Thin wrapper that builds the internal GTM / sales version (`gtm-main.pdf`) |
| `references.bib` | BibTeX bibliography |
| `mlsys2026.sty`, `mlsys2026.bst` | Official MLSys 2026 style and bibliography style |
| `fancyhdr.sty`, `algorithm.sty`, `algorithmic.sty` | Bundled with the official MLSys zip |
| `figures/` | Paper figures (SVG sources + PDF companions) |

## Compile locally

From this directory (`docs/whitepaper/`):

```bash
cd docs/whitepaper
latexmk -pdf main.tex
```

Equivalent manual sequence:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Requirements: a TeX distribution with `pdflatex`, `bibtex`, and common packages (`graphicx`, `booktabs`, `microtype`, `natbib`, `hyperref`).

This project was smoke-tested by compiling `main.tex` successfully (PDF produced). On Overleaf, use the default **pdfLaTeX** engine.

## Figures

Figures live in `figures/`. Each paper figure has:

* an `.svg` source (editable / regenerated by `scripts/render_whitepaper_figures.py`)
* a matching `.pdf` used by LaTeX (`\includegraphics{...pdf}`)

SVGs are **not** included directly via the `svg` package. PDF companions keep compilation simple on Overleaf and with `pdflatex` (no Inkscape shell escape required).

| LaTeX label | PDF file |
| --- | --- |
| `fig:what-is-preserved` | `figures/fig1-what-is-preserved.pdf` |
| `fig:search-pipeline` | `figures/fig2-search-pipeline.pdf` |
| `fig:headline` | `figures/fig3-headline-solve-rates.pdf` |
| `fig:warehouse-arms` | `figures/fig4-warehouse-arms.pdf` |
| `fig:warehouse-tokens` | `figures/fig5-warehouse-tokens.pdf` |
| `fig:failure-modes` | `figures/fig6-failure-modes.pdf` |

To regenerate chart PDFs after editing the renderer:

```bash
# from repo root
uv run python scripts/render_whitepaper_figures.py
# then convert SVG -> PDF (matplotlib charts can also be saved as PDF from the renderer)
```

## Upload to Overleaf

1. Zip the contents of this `whitepaper/` directory (or the whole folder).
2. On Overleaf: **New Project → Upload Project**.
3. Set the main document to `main.tex` if Overleaf does not detect it.
4. Compile with pdfLaTeX (default). BibTeX should run automatically.

You do **not** need a separate `paper/` or `mlsys/` folder. Keep Markdown and LaTeX together here.

## Build modes

All content lives in `main.tex`. Two entry points compile it for two audiences,
so the PDFs can never drift apart:

```bash
latexmk -pdf main.tex      # -> main.pdf      blind MLSys submission
latexmk -pdf gtm-main.tex  # -> gtm-main.pdf  internal GTM / sales version
```

| Output | Authors shown | PDF metadata author | First-page notice |
| --- | --- | --- | --- |
| `main.pdf` | no | `Anonymous Authors` | "Preliminary work. Under review by the ... (MLSys) Conference." |
| `gtm-main.pdf` | yes, with affiliations and contact email | real names | "Preprint. Not peer reviewed and not published." |

`gtm-main.tex` works by defining `\preprintbuild` before inputting `main.tex`.
You can also toggle the same flag directly inside `main.tex`:

```latex
% \def\preprintbuild{}
```

Only ever upload `main.pdf` to the submission site. `gtm-main.pdf` shows author
names and would break double-blind review.

In Overleaf, set the main document to whichever of the two you want to compile.

The preprint mode deliberately overrides the notice string. The template's
`[accepted]` option would otherwise stamp "Appearing in the Proceedings of the
9th MLSys Conference", which would falsely imply the paper was published.

At camera-ready, drop the override and use the official style file for the
target year and track.

## Target venue

MLSys 2027, industrial track. Submissions open Oct 10, 2026 and close
Oct 30, 2026 20:00 UTC. Papers are up to 10 pages excluding references, and
every reference must list all authors explicitly.

Industrial track rules differ from the research track: author names must still
be withheld, but the content does **not** need anonymizing, so company names,
product names, and URLs are allowed. Tracks cannot be switched after the
deadline.
