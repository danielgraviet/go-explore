## Coding Principles

* Prefer simple, clear solutions over unnecessary complexity.
* Favor readable, idiomatic Python.
* Keep code concise without sacrificing correctness or maintainability.
* Avoid excessive comments. Comment only when the reasoning is not obvious from the code.
* Keep responses concise and token-efficient while maintaining high code quality.
* Follow established software-engineering best practices, including SOLID principles and relevant Gang of Four design patterns.
* Use design patterns only when they simplify the code or make it easier to extend. Do not over-engineer.
* Prefer small, focused components with clear responsibilities.
* Optimize for code that another engineer can quickly understand, test, and modify.
